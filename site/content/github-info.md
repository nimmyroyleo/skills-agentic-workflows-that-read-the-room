## Recent updates worth watching

- **Agentic workflows automate repo tasks with plain English.** Agentic Workflows are AI-powered automations that run coding agents in GitHub Actions, written in markdown and triggered by schedules, events, or slash commands — useful for issue triage, daily reports, and compliance checks. (Source: Awesome Copilot, awesome-copilot.github.com/learning-hub/agentic-workflows)
- **Copilot code review effort levels are now generally available**, letting teams tune how deep Copilot's automated reviews go on pull requests. (Source: GitHub Changelog, 2026-08-07)
- **Trigger Copilot automations directly from comments**, making it easier to kick off agent tasks without leaving an issue or PR conversation. (Source: GitHub Changelog, 2026-08-03)
- **Agent plugins reached 1.0** across VS Code, the Copilot CLI, and the Copilot app, giving developers a consistent way to extend Copilot with custom tools everywhere they work. (Source: GitHub Changelog, 2026-08-12)
- **Label archiving is generally available**, helping maintainers retire old labels without losing their history on existing issues and PRs. (Source: GitHub Changelog, 2026-08-27)
- **Pin projects, views, and milestones to the repository sidebar** for faster access to the boards and plans a team checks daily. (Source: GitHub Changelog, 2026-08-20)
- **The GitHub Copilot app now has a "My work" tab**, a mission-control view for tracking active Copilot sessions and pull requests in one place. (Source: GitHub Blog, github.blog/ai-and-ml/github-copilot)
- **New beginner tutorials show how to automate recurring developer tasks with the GitHub Copilot app**, including writing your first prompt and managing Dependabot PR triage. (Source: GitHub Blog, github.blog/ai-and-ml/github-copilot)
